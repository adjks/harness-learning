任务执行

查询、摘要、写作、自动化，并把结果回到门户或知识库。

采集 / 清洗 / 分块 门户中的图书、文档和系统链接进入知识整理流程。
MCP / REST API 知识库把检索、上传和管理能力暴露给 Agent CLI。
深链 / 搜索入口 / 上下文引用 门户与 Agent 都可以回到 Wiki、RAG 问答或内部系统。

门户负责发现

它不是另一个知识库，而是把图书、文档、系统入口和问答深链组织成一个总导航。

知识库负责沉淀

WeKnora / LLMWiki 把材料变成 Wiki、图谱、RAG 检索和可被 MCP / API 调用的能力。

Agent 负责行动

Pi Agent CLI 连接人、知识库和内部系统上下文，让知识进入实际任务执行过程。

这版采用稳定的泳道式信息图布局，避免使用漂浮窗口和自由曲线箭头；适合继续构思，也适合后续导出为汇报用图片。
